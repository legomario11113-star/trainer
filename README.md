# Тренер — дневник тренировок

Офлайн-приложение (PWA) для записи тренировок на двоих. Все данные хранятся только на телефоне.

**Открыть:** https://legomario11113-star.github.io/trainer/

## Установка на телефон
- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** открыть в Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».

## Как пользоваться
**Тренер:** «Ещё» → «Синхронизация» → токен GitHub (только `gist`) → «Создать хранилище». Вкладка «Тренер» → добавить клиента → составить план → «Сохранить план» → «Ссылка для клиента».

**Клиент:** открыть ссылку (iPhone — в Safari → «На экран „Домой“»). Видит только свой план и дневник. ✓ — подход выполнен и пошёл отдых, ✓ ещё раз — отдых записан. «Завершить тренировку» → тренер видит результат.

Устройство и решения — в `PROJECT_NOTES.md`.

## Формат плана (для Claude)
```json
{ "plans": { "me": { "week": "...", "rule": "...", "days": [
  { "id": "me-mon", "label": "Пн", "title": "...", "exercises": [
    { "name": "Жим лёжа", "type": "wr", "sets": 3, "reps": "8", "rest": 150, "hint": "...", "test": false }
  ] } ] }, "her": { ... } } }
```
`type`: `wr` — вес × повторы, `r` — повторы, `t` — время (сек), `cardio` — минуты/км/уровень. Ключи `plans` — id клиентов (исторические `me`, `her`).

## Обновление
После изменения файлов увеличить `VERSION` в `sw.js`.
