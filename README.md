# Тренер — дневник тренировок

Офлайн-приложение (PWA) для записи тренировок на двоих. Все данные хранятся только на телефоне.

**Открыть:** https://legomario11113-star.github.io/trainer/

## Установка на телефон
- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** открыть в Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».

## Как пользоваться
1. Вверху выбрать профиль, ниже — день плана.
2. Вписывать вес и повторы, отмечать ✓ — запустится таймер отдыха. Пустой подход при ✓ заполнится значениями предыдущего.
3. «Завершить тренировку» → оценка самочувствия → сохранено в «Историю».
4. «Ещё» → «Выгрузить дневник (.md)» → отправить файл Claude.
5. Новый план от Claude (`.json`) — «Ещё» → «Загрузить новый план».

## Синхронизация
«Ещё» → «Синхронизация». На первом устройстве — токен GitHub (только права `gist`) → «Создать хранилище».
Коды подключения: **полный** (оба профиля — для своих устройств) и **код девушки** (только её профиль).
Каждый профиль — отдельный файл в gist, зашифрованный своим ключом (AES-GCM). Ключ профиля девушки выводится из главного ключа, поэтому её код не открывает чужие данные.

## Формат плана (для Claude)
```json
{ "plans": { "me": { "week": "...", "rule": "...", "days": [
  { "id": "me-mon", "label": "Пн", "title": "...", "exercises": [
    { "name": "Жим лёжа", "type": "wr", "sets": 3, "reps": "8", "rest": 150, "hint": "...", "test": false }
  ] } ] }, "her": { ... } } }
```
`type`: `wr` — вес × повторы, `r` — повторы, `t` — время (сек), `cardio` — минуты/км/уровень. Можно передать только `me` или только `her`.

## Обновление
После изменения файлов увеличить `VERSION` в `sw.js`.
